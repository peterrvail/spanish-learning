## Clitic Forms

### Direct Object Pronouns (me, te, lo, la, nos, os, los, las)

| Person | Clitic | Example |
|--------|--------|---------|
| 1st singular | **me** | Me ves. (You see me.) |
| 2nd singular | **te** | Te amo. (I love you.) |
| 3rd singular (masc.) | **lo** | Lo compré. (I bought it.) |
| 3rd singular (fem.) | **la** | La espero. (I'm waiting for her.) |
| 1st plural | **nos** | Nos llamó. (He called us.) |
| 2nd plural (vosotros) | **os** | Os veo. (I see you all.) |
| 3rd plural | **los** | Los conozco. (I know them.) |
| 3rd plural (fem.) | **las** | Las vendí. (I sold them.) |

### Indirect Object Pronouns (me, te, le, nos, os, les)

| Person | Clitic | Example |
|--------|--------|---------|
| 1st singular | **me** | Me dio un regalo. (He gave me a gift.) |
| 2nd singular | **te** | Te conté la verdad. (I told you the truth.) |
| 3rd singular | **le** | Le escribí. (I wrote to him/her.) |
| 1st plural | **nos** | Nos habló. (He spoke to us.) |
| 2nd plural (vosotros) | **os** | Os mostré. (I showed you all.) |
| 3rd plural | **les** | Les enviamos un correo. (We sent them an email.) |

### Reflexive Pronouns (me, te, se, nos, os, se)

| Person | Clitic | Example |
|--------|--------|---------|
| 1st singular | **me** | Me levanto. (I get up.) |
| 2nd singular | **te** | Te despiertas. (You wake up.) |
| 3rd (singular & plural) | **se** | Se baña. (He/she bathes.) |
| 1st plural | **nos** | Nos dormimos. (We fell asleep.) |
| 2nd plural (vosotros) | **os** | Os sentáis. (You all sit down.) |

## Clitic Position Rules

### Rule 1: Standard Preverbal Position (Indicative)

**In most cases**, clitics appear **before** the conjugated verb:

```
Subject + CLITIC + Verb + (Object)

Te llamo mañana.        (I'll call you tomorrow.)
Lo vimos ayer.          (We saw it yesterday.)
Les enviamos el paquete. (We sent them the package.)
```

### Rule 2: Postverbal Position (Affirmative Imperative)

**In affirmative imperatives**, clitics attach **to the end** of the verb:

```
Verb + CLITIC (attached)

¡Llámame!       (Call me!)
¡Cómelo!        (Eat it!)
¡Envíanos un mensaje! (Send us a message!)
¡Abrelo!        (Open it!)
```

**Stress shift with accent marks:**
- Single clitic on 2-syllable verb → no accent typically
- Single clitic on 3+ syllable verb → accent on the original stress syllable
- Multiple clitics → accent on the main stress

Examples:
- habla + me = **Háblame** (accent added to preserve stress)
- mira + lo = **Miralo** (short form, could be Míralo)
- compra + nos + lo = **Compranooslo** → **Cómpranoslo** (accent added)

### Rule 3: Preverbal Position (Negative Imperative)

**In negative imperatives**, clitics appear **before** the verb (subjunctive form):

```
No + CLITIC + Verb (subjunctive)

No me llames.           (Don't call me.)
No lo comas.            (Don't eat it.)
No nos envíes un correo. (Don't send us an email.)
No se lo digas.         (Don't tell him/her that.)
```

## Double Object Pronouns

### The Golden Rule

**When both direct and indirect object pronouns appear, the indirect comes first:**

```
IO + DO

Indirect (me, te, le, nos, os, les) + Direct (lo, la, los, las)
```

### Standard Examples

| Indirect + Direct | Spanish | English |
|-------------------|---------|---------|
| me + lo | Me lo compró. | He bought it for me. |
| te + la | Te la presté. | I lent it to you. |
| le + los | Le los mostré. | I showed them to him/her. |
| nos + las | Nos las enviaron. | They sent them to us. |
| os + lo | Os lo dije. | I told it to you all. |
| les + la | Les la expliqué. | I explained it to them. |

### The SE Substitution Rule

**When the indirect object pronoun is `le` or `les`, it changes to `se` before a direct object pronoun:**

```
le + lo/la/los/las → se + lo/la/los/las
les + lo/la/los/las → se + lo/la/los/las
```

**Examples:**

| Wrong | Correct | English |
|-------|---------|---------|
| ~~Le lo expliqué~~ | **Se lo expliqué.** | I explained it to him/her. |
| ~~Les las vendí~~ | **Se las vendí.** | I sold them to them. |
| ~~Le los compré~~ | **Se los compré.** | I bought them for him/her. |

### Double Clitics in Affirmative Imperative

In affirmative imperatives, double clitics attach to the verb. **Always indirect before direct:**

```
Verb + IO + DO (attached)

Dímelo.        (Tell me it.) — di + me + lo
Cuéntaselo.    (Tell it to him.) — cuenta + se + lo
Compranoslos.  (Buy them for us.) — compra + nos + los
Muestramela.   (Show it to me.) — muestra + me + la
```

### Double Clitics in Negative Imperative

In negative imperatives, clitics appear before the verb:

```
No + IO + DO + Verb (subjunctive)

No me lo digas.      (Don't tell me it.)
No se la cuentes.    (Don't tell it to him/her.)
No nos los compres.  (Don't buy them for us.)
```

## Clitic Attachment in Different Structures

### Infinitives (Postverbal Attachment)

Clitics attach to the end of infinitives:

```
Infinitive + Clitic(s)

Quiero comprarlo.         (I want to buy it.) — comprar + lo
Necesito decirte algo.    (I need to tell you something.) — decir + te
Prefiero no comerla.      (I prefer not to eat it.) — comer + la
Espero poder verte pronto. (I hope to see you soon.) — ver + te
```

**With double clitics:**

```
Debo mostrártelo.      (I should show it to you.) — mostrar + te + lo
Quiero explicárselo.   (I want to explain it to him/her.) — explicar + se + lo
Necesitamos comprároslas. (We need to buy them for you all.) — comprar + os + las
```

### Gerunds (Postverbal Attachment)

Clitics attach to the end of gerunds:

```
Gerund + Clitic(s)

Viéndolo claramente... (Seeing it clearly...) — viendo + lo
Diciéndome la verdad... (Telling me the truth...) — diciendo + me
Comprándoselo... (Buying it for him/her...) — comprando + se + lo
```

**Accent always required on gerunds with clitics:**

```
viendo + lo = **viéndolo** (accent on the e)
diciendo + me = **diciéndome** (accent on the i)
mostrando + nos + la = **mostrándonosla** (accent on the a)
```

### Participles (Postverbal Attachment with Negation)

In negative participles (rarely used):

```
No + Participle + Clitic(s)

Sin decirlo.           (Without saying it.) — decir + lo
Sin comprarlo.         (Without buying it.) — comprar + lo
```

### Progressive Constructions (estar + gerund)

Clitics can attach to **either** the auxiliary or the gerund:

```
Está mirándolo.    OR    Lo está mirando.
(He's looking at it.)

Se están preparando.  OR  Están preparándose.
(They are getting ready.)
```

## Common Errors

### Error 1: Wrong Clitic Order in Double Pronouns

❌ **Incorrect:** No lo me digas. (wrong order: DO before IO)  
✅ **Correct:** No me lo digas. (Indirect IO before DO)

---

### Error 2: Forgetting the SE Substitution

❌ **Incorrect:** Le lo expliqué.  
✅ **Correct:** Se lo expliqué.

---

### Error 3: Clitic Position in Affirmative Imperative

❌ **Incorrect:** Me lo compra. (preverbal, as if indicative)  
✅ **Correct:** Cómpramelo. (postverbal, affirmative imperative)

---

### Error 4: Missing Accent on Gerunds/Participles with Clitics

❌ **Incorrect:** viendolo (no accent, stress unclear)  
✅ **Correct:** viéndolo (accent preserves the original stress)

---

### Error 5: Clitic Position in Negative Imperative

❌ **Incorrect:** Dímelo no. (clitic after negation)  
✅ **Correct:** No me lo digas. (clitics before subjunctive form)

## Practice Patterns

### Pattern 1: Affirmative → Negative Imperative

Conjugate the verb in both affirmative and negative imperative forms:

```
Affirmative Imperative: Dímelo.
↓
Negative Imperative: No me lo digas.

Rule: Position changes from postverbal (affirmative) to preverbal (negative).
```

**Drill examples:**

1. Dímelo. → No me lo digas.
2. Cómpramelo. → No me lo compres.
3. Muéstrasela. → No se la muestres.
4. Envíanoslos. → No nos los envíes.

---

### Pattern 2: Indicative → Imperative

Convert an indicative sentence to an affirmative imperative with clitics:

```
Indicative: Lo compré. (I bought it.)
↓
Imperative: ¡Cómpralo! (Buy it!)

Subject drops, clitic attaches postverbally.
```

**Drill examples:**

1. Te lo expliqué. → ¡Explícatelo!
2. Me lo prestaron. → ¡Préstamelo!
3. Se lo enviaron. → ¡Envíaselo!

---

### Pattern 3: Double Clitic Substitution

Convert direct pronouns to double clitics (IO + DO):

```
Input: Le expliqué el problema.
↓
Output: Se lo expliqué. (substitution: le → se before lo)

Rule: le/les → se when followed by a DO pronoun.
```

**Drill examples:**

1. Le compré un regalo. → Se lo compré.
2. Les envié un correo. → Se lo envié.
3. Le mostré las fotos. → Se las mostré.

---

### Pattern 4: Infinitive Attachment

Rewrite using infinitive + clitic attachment:

```
Input: Quiero decirte un secreto.
↓
Output: Quiero decirte un secreto. (already correct; te attaches to infinitive)

Alternative: Te quiero decir un secreto. (clitic before conjugated verb)

Both are grammatically correct.
```

**Drill examples:**

1. Debo mostrarte algo. OR Te debo mostrar algo.
2. Necesito explicárselo. OR Se lo necesito explicar.
3. Prefiero no comprarlo. OR No lo prefiero comprar.

## Quick Reference Checklist

Use this checklist when constructing clitic sentences:

- [ ] Identified the direct object (what/whom)?
- [ ] Identified the indirect object (to/for whom)?
- [ ] Correct clitic form selected (me, te, lo, le, etc.)?
- [ ] **Correct order** (IO before DO in double pronouns)?
- [ ] **SE substitution** applied (if le/les + DO)?
- [ ] **Correct position**:
  - Affirmative imperative → postverbal (attached)
  - Negative imperative → preverbal (before verb)
  - Infinitive/Gerund → postverbal (attached)
  - Indicative → preverbal (before verb)
- [ ] **Accents added** on gerunds/affirmative imperatives with clitics?
